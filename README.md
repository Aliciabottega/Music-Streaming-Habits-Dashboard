  ### Project Overview

  This project analyzes listener behavior across genres, moods, platforms and engagement patterns to
  uncover how people interact with music day to day. It goes beyond simple play counts to look at listening depth, skip behavior and discovery patterns.

  ### Data Source

  This data source is a "Music Streaming Habit.csv" file from kaggle

  ### Tools

  - Data Analysis & Visaualization : Power BI
 
  ### Data Analysis

  During this analysis, I was able to :

  - Calculate average daily listening minutes

  - Identify top countries, platforms, artists and genres by their listening minutes

  - Calculate average skip rate
 
  - Identify mood, platform and subscription that has the highest skip rate as this tells us how often listeners abandon or skip a song 

  ### Results

  From the following analysis, I found out :

  - Average average daily listening minutes is 139 minutes

  - Top country, platform, artist and genre by their listeneing minutes are Japan ( country ), Spotify ( platform ),
    SZA ( artist ) & Pop ( genre )

  - Average skip rate is 28 %
 
  - Mood, platform and subscription with the highest skip rate are Workout ( mood ), Amazon music ( platform ) & Free ( subscription )

  ### Recommendation

  These findings can help a streaming platform better support its listeners — for example,
  genre based playlist curation could improve retention among high skip rate listeners.
